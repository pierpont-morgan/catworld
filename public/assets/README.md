# 美术素材放置说明

把你的图片(推荐 **PNG，带透明背景**)放进这个文件夹 `public/assets/`。
Vite 会把 `public/` 下的文件发布到网站根路径,所以
`public/assets/cat.png` 在代码里的地址就是 `/assets/cat.png`。

放好图后，在 `src/assets/manifest.ts` 里给对应条目填 `file` 字段即可，例如：

```ts
{ key: "cat", frameWidth: 48, frameHeight: 48, file: "/assets/cat.png" },
```

## 各素材的规格

| key     | 用途   | 期望尺寸/帧                                  |
|---------|--------|----------------------------------------------|
| `cat`   | 猫咪   | 雪碧图（spritesheet），每帧同样大小，从左到右排列。当前动画用到 4 帧：0=待机 1=走A 2=走B 3=攻击 |
| `slime` | 敌人   | 雪碧图，2 帧：0=待机A 1=待机B                  |
| `tiles` | 地图瓦片 | 一排 8 个瓦片，**顺序固定**：草·路·水·沙·森林·花·树·石（树/石需透明底） |

## 名词解释

- **雪碧图 / spritesheet**：把动画的每一帧拼在一张大图里。比如猫有 4 帧、每帧 48×48，
  那整张图就是 192×48（4 帧横排）。`frameWidth/Height` 告诉程序每一格多大。
- 如果你的图**只有一张静态图、没有动画帧**，也能用，只是要把对应动画改成只引用第 0 帧——
  这种情况直接把图发我，我帮你改清单。
